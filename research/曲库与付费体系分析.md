# 古琴大师 APK · 曲目库与付费体系分析

## 一、曲目库：不在 APK 里，在云端

「内置曲目」其实是**云端琴谱库**（Supabase 表 `latest_score_content_versions`，
`entity_type=library_item`，RPC 名就叫「服务器琴谱库」）。APK 本地 assets 只有
减字谱引擎的三份数据 JSON，没有任何谱面。

全是 `change_source=admin_approve`——即**用户投稿 → 管理员审核上架**的 UGC 曲库
（另有 77 份帖子附带的谱面版本）。上架流程表：`score_submissions`（status/
review_reason/score_reviewed_by）+ `posts`（score_review_* 字段）。
传统曲目只有《阳关三叠》《诀别书》《沧海一声笑》级别，其余是流行曲移植。

### 谱面数据格式（完整可读、可复用）

```json
{"score":{"lines":[{"jianziTokens":[
  {"code":"shiqigouyi","kind":"jianzi","text":"食七勾一",
   "partIds":["002","013","021","007"],          // 引用 glyph_parts 的部件 id
   "categorySlots":["左手","number","勾剔摘","number"], // 语法槽
   "slotTransforms":[{x,y,lengthX,lengthY},...],   // 256×256 方块内的排版
   "semanticCategories":[...], "endsSentence":true}
]}]}}
```
即**渲染信息全在数据里**：拿到 token 就能用 glyph_paths.json 直接画出这个减字，
不需要引擎代码。谱面另含节奏/断句（endsSentence、延音线等字段）。

## 二、付费体系

### 定价
- **终身会员：一次付清 ¥368，权益终身有效**（LifetimeMembershipOffer）。
- 会员计划表 `membership_plans` 按月/季/年/终身（month/quarter/year/lifetime）设计，
  但当前查库为空——**尚未配置订阅档，只卖终身**。
- 支付：微信支付（prepayid 流程）+ Apple IAP（双通道）。

### 什么要钱（从字符串与符号还原）
VIP 权益（拦截弹窗 MembershipAccessDialog）：
- **点读器**（点击减字发声）
- **逐字练**（TanbaSentenceEvaluation 单字模式）
- **整句练**（句子级跟弹评分）
- **MusicXML 导入**（五线谱/简谱转减字谱）
- **编辑他人琴谱**
- **导出 PDF**
- **全部琴谱**（会员有效期内开放全部功能和全部琴谱）

### 什么免费
- 模拟器弹奏本体、减字谱编辑器、曲库浏览
- **点读器前 25 个减字免费试听**（含控制符、旁字）
- **免费练习时长**：新用户有免费练习时间池（「免费练习剩余 X 小时」「免费练习已到期」），
  弹拨（Tanba）逐句功能带试用限额（_trialLimitSentenceCount/_trialLimitTicks）
- **投稿换会员**：「录入并发布你的琴谱，即可在一个月内免费使用点读器、逐字练和
  整句练等 VIP 练习功能」——UGC 曲库的冷启动激励，与王悠荻网站「录琴音上地图」
  同一思路。
- 试用期内不能下单（「免费体验不能创建支付订单」）。

### 货币化外围
- **打赏体系**：tip_orders/tip_records/creator_income（总额/待入账/已提现，
  platform_fee_bps 平台抽成）——谱作者可直接获得收入。
- 社区：posts/likes/comments/follows/私信 conversations、练习日历打卡、练习值
  （user_practice_values，疑似激励系数）。

## 三、后端与安全边界

- Supabase 自托管域名 supabase.opentrust.net，41 张表 + 20 个 RPC。
- anon key 内嵌 APK（208 字符 JWT，role=anon）——**用它能读全部曲库谱面**
  （如上，已抓），但写操作被 RLS 拦截；会员下单走 Edge Function
  （create-membership-order / complete-membership-order），未登录返回「登录已失效」，
  无越权漏洞。
- 订单表 membership_orders（amount_cents/list_price_cents/discount_cents）anon 不可读。

## 四、一句话总结

这是**「工具免费 + 练习功能订阅化（¥368 买断）+ UGC 曲库（投稿换会员）+
谱作者打赏分成」**的商业模型；曲目库和谱面数据对匿名完全开放（等于公开 API），
真正的付费墙只在客户端练习功能与导出上，服务端鉴权完整。
