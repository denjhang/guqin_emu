# 虚拟古琴（udywang.com/guqin）研究报告

调研日期：2026-09-10
对象：https://udywang.com/guqin/?entry=free&lang=zh
作者：王悠荻（Wang Youdi），公开发布 2026-08-20，当前内核版本 v2.14（2026-08-28）

## 一、产品是什么

一个纯浏览器端可演奏的「虚拟古琴」Web 应用：Canvas 画的琴面（七弦十三徽），
点击弦与徽位交点即可发声，支持散音 / 按音 / 泛音三种音色、走手滑音、录制演奏并
上传到「世界古琴地图」与全球用户分享。另有节奏游戏式打谱模式（仙翁操、秋风词）
和音位查询页（/guqin-yinwei.html）。

## 二、页面与功能结构

- 自由演奏（entry=free 默认）：琴面点按出声，按住拖动为走手音（上滑/下滑，
  音高连续变化）；左上「录制你的专属琴音」；「古琴地图」跳 /world-map。
- 泛音/按音切换按钮：泛音模式点徽位出泛音，按音模式可按住滑。
- 音位全览：琴面上叠加显示所有泛音音位的简谱标注（7 弦 × 13 徽）。
- 中英双语（?lang=zh/en），自托管统计 analytics.js + Cloudflare Insights。
- 页脚：Virtual Guqin © 2026 Wang Youdi。

### 世界古琴地图（/world-map）
- Leaflet + 高德地图，琴形 marker 聚合显示全球用户演奏。
- 顶部统计（本次调研时）：131 个琴音片段、7,513 个演奏音符、37 个地区。
- 右侧排行榜：曲名/昵称、♥ 点赞数、城市·地区·国家、音符数、日期、播放/点赞按钮、
  ▶ 播放次数。热门曲目：忆故人、潇湘水云、酒狂、平沙落雁、梅花三弄、沧海一声笑等，
  还有不少「祝王老师生日快乐」类社区内容——明显有一个活跃的小型琴友社区。

## 三、技术实现（重点）

### 总体
- **无任何前端框架**：原生 JS + 2D Canvas + Web Audio（AudioContext），DOM 只承载
  按钮和面板。单 HTML 页 + 约 13 个脚本分片按模块加载（part-01~07、world-recorder、
  world-replay），各自带 `?v=` 版本号做缓存刷新，Cloudflare 托管。
- 两个 canvas：`#cv`（1236×606，主琴面）和 `#mqin`（300×150，角落迷你琴，
  点哪根弦响哪根，用于解锁 AudioContext，避免正式开局第一个音哑掉）。

### 数据层（都在 window 全局对象上）
- `GUQIN_DATA`（part-01，约 41KB JSON）：
  - `OPEN`：7 条散音（正调定弦 C2 D2 F2 G2 A2 C3 D3，midi 36/38/41/43/45/48/50）
  - `POSITIONS`：105 个按音位，每项含 x（弦长百分比）、徽位名（含十徽八分、
    七徽九分等分数徽位）、简谱音名、八度、midi、频率
  - `HARMONICS`：7×13=91 个泛音位（每徽 × 每弦的准确音高）
  - `STRING_LINES`/`HUI_MARKS`/`HUI_LABELS`：琴面几何（弦的起止 y、13 徽的
    弦长百分比位置）
- `GUQIN_SAMPLES`（part-02）：音源清单 v1.87——**105 按音 + 7 散音 + 49 泛音全部是
  真实录音**（audio/pressed/、audio/open/、audio/harm/ 下的独立 M4A，按需加载）。
  注释里写明以前是 4.37MB base64 内联，后改为按需取用。
- `GUQIN_POOL`（part-03）：约 100 条减字谱语料（tech 散/按、弦、徽、jzp 减字序号、
  绰/注标注），用于随机生成有句法的谱面。
- `GUQIN_JZP` + part-06：内置《秋风词》整曲谱面（逐字按量字谱核对，注明不用
  简谱音高反推）。
- `GUQIN_DEMO`（part-04）：王悠荻老师《仙翁操》示范录音（audio/demo.mp3，演示时才取）。
- `GUQIN_GEST`（part-05）/ `GUQIN_MORPH_AUDIO`（part-07）：走手音「撞」及
  上滑/下滑起止音素材（audio/morph/），滑音 = 起止真实采样间做 morph。

### 演奏内核（part-07，约 288KB，注释即完整开发日志）
- 参考了音游的成熟做法：**bemuse 时钟与分档判定窗口、Arcaea 定额计分、
  osu! 时间本位落速**。自带判定系统（早/晚 ms 提示、走手音、泛音双音和声判定）。
- 打谱模式：《仙翁操》三档难度（0.5×/1.0×/1.5×，只改速度与提示量，谱面判定不变），
  音珠挂真实减字谱字形（从原谱抠出的 alpha 图），暂停真停时钟（AudioContext
  suspend/resume），空格暂停、回车重来、Esc 退出。
- 配色/设计细节讲究：暖金=普通音、月白青瓷=下一音、胭脂=走手音、碧青=泛音，
  一律「浅底深字」保证可读；琴弦粗细一弦 2.1px → 七弦 0.85px 仿真琴。
- 嵌入场景设计：`html.world-replay` 时琴面是「回放屏」，只看不弹；`?embed=home`
  时作为嵌页组件。代码中预留「AI 陪练」待办（听真琴、评时机音准）。

### 后端（world-recorder.js / world-replay.js）
- 唯一 REST 端点：`/api/performances`（GET 列表 / POST 上传）。
- 演奏以**事件流**存储（每个音符的弦/徽位/时值），不是音频文件；回放时用同一
  采样引擎现场重演（world-replay.js），还带 Enhanced 视觉。
- 身份：本地 localStorage 生成 `world-guqin-user-id-v1`（无登录）；
  另存删除凭据 `world-guqin-delete-credentials-v1`（作者可删）；点赞/播放计数
  在服务端。地理位置由服务端 IP 反查（country/region/city/lat/lng）。
- GET 返回示例字段：id、userId、nickname、recordedAt、durationMs、eventCount、
  likeCount、playCount、location、appVersion。

## 四、工程上值得借鉴的点

1. **真实采样 + 事件流回放**：录音资产按需加载（解决 4.37MB 内联教训），演奏是
   JSON 事件而非音频，社区分享的带宽成本极低，且可被二次创作/分析。
2. **乐理数据建模严谨**：徽位用弦长百分比（徽位本来就是弦长等分点），按音含
   分数徽位，泛音 7×13 全表，正调定弦频率全部硬数据。
3. **游戏化但克制**：音游判定引擎移植自然（减字谱谱面 + 分档难度只动速度）；
   随机谱面有「句法」规则（勾挑相间、弦号跳变≤2）。
4. **渐进解锁音频**：迷你琴唤醒 AudioContext 的细节。
5. **版本注释即文档**：part-07 头部几千字的版本日志记录每个设计决策和修音/修色
   的原因（甚至有琴人反馈「绿不拉几」这类真实用户语言），是很好的独立开发者
   迭代样本。
6. **轻后端**：一个 JSON API + localStorage 匿名身份 + 静态托管，撑起全球社区地图。
